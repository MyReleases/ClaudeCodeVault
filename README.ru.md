# handoff-vault

**Бэкап, перенос и передача проектов Claude Code без потери чатов.**

[English](README.md)

Claude Code хранит каждый разговор в `~/.claude/projects/<закодированный путь папки>/`. Это работает,
пока вы не:

- **перенесли или переименовали папку проекта:** чаты на месте, но `claude --resume` в новой папке
  их не видит;
- **захотели бэкап:** история лежит в папках вида `C--Users-me-Desktop-my-app`, вперемешку с форками,
  которые ссылаются на чужие пути;
- **переехали на другой компьютер или аккаунт:** экспорта вместе с чатами нет;
- **ведёте один чат неделями:** каждое сообщение перечитывает всю историю, длинный чат медленный
  и дорогой.

`handoff-vault` — один файл на Python без зависимостей, который решает все четыре проблемы.

## Установка

Нужен только Python 3.8+.

```bash
pipx install git+https://github.com/MyReleases/handoff-vault
```

Или скачайте [`handoff_vault.py`](handoff_vault.py) и запускайте `python handoff_vault.py <команда>`.

## Команды

| Команда | Что делает |
|---|---|
| `status` | Все проекты с историей: чаты, размер, последняя активность. Помечает **«сирот»** — чаты, чья папка перенесена или удалена. |
| `backup ПАПКА` | Копирует всю историю в `ПАПКА/<проект>__<хэш>/` с `manifest.json`. Только новое, ничего не удаляет. |
| `move СТАРЫЙ НОВЫЙ` | Переносит папку **вместе с чатами** и переписывает пути внутри, чтобы `claude --resume` работал на новом месте. `--history-only`, если папку уже перенесли руками; `--from-backup ПАПКА` — восстановить из бэкапа; `--dry-run` — только показать. |
| `export [ПРОЕКТ]` | Один zip: проект, его чаты и описание. Без `node_modules`, `.venv`, `dist` и т. п. **Останавливается, если в чатах есть секреты** (см. `scan`), пока не укажете `--redact` или `--allow-secrets`. |
| `import ZIP ПАПКА` | Распаковывает экспорт где угодно (другой компьютер, другой аккаунт) и перепривязывает чаты к новой папке. |
| `scan [ПРОЕКТ] / --all` | Ищет в истории ключи API, токены GitHub/Slack/Stripe/Telegram и приватные ключи. В чатах часто остаются секреты, которые вы вставили или которые напечатал инструмент. |
| `stats [--days 7]` | Активность по проектам: ваши сообщения, активные чаты, коммиты, изменённые файлы. `--json` для дашбордов. |
| `init [ПРОЕКТ]` | Кладёт `CLAUDE.md`, `HANDOFF.md` и команду `/handoff` (ничего не перезаписывает). |

## Привычка, которая экономит больше всего токенов

1. **`CLAUDE.md`** — то, что не меняется: стек, команды, правила. Коротко: он читается в каждом сообщении.
2. **`HANDOFF.md`** — состояние работы: цель, сделано, следующий шаг, решения, проблемы. Один экран.
3. **Одна задача — один чат.** Чат разросся или начал сжиматься — наберите **`/handoff`**, Claude
   обновит `HANDOFF.md`. Откройте новый чат: *«прочитай HANDOFF.md и продолжим»*. Новый чат
   начинает с одного экрана контекста, а не с мегабайтов истории.
4. Время от времени **`handoff-vault backup`**, чтобы старые чаты не потерялись.

`handoff-vault init` настраивает пункты 1–3 за секунду.

## Безопасность

- Ничего не удаляется. `move` копирует историю на новое место, а старую оставляет: в `status` она
  будет «сиротой». Удалите её сами, когда убедитесь, что всё в порядке.
- `move` не перезаписывает существующую папку и существующие чаты (для чатов — только с `--force`).
- `import` проверяет все пути в архиве до записи первого файла.
- `scan` и `export` никогда не печатают секрет целиком.

## Ограничения

- **Боковая панель приложения Claude.** Приложение хранит свой список сессий. После `move`
  продолжайте в терминале через `claude --resume` или начните новый чат в новой папке.
- **Очень длинные пути** (больше ~200 символов): новые версии Claude Code могут сокращать имя папки
  истории, и перенесённый чат может не появиться в `--resume`. Напишите issue, если столкнётесь.
- **Точки отката файлов:** пути в снимках файлов не переписываются, `/rewind` правок, сделанных
  *до* переноса, может не найти файлы.
