# ClaudeCodeVault

**Больше ни одного потерянного чата Claude Code.** Бэкап разговоров с ИИ-помощником, перенос
проектов без поломки `claude --resume`, переезд на другой компьютер и короткие чаты, которые
тратят меньше токенов.

[![tests](https://github.com/MyReleases/ClaudeCodeVault/actions/workflows/tests.yml/badge.svg)](https://github.com/MyReleases/ClaudeCodeVault/actions/workflows/tests.yml)
&nbsp;Один файл на Python · без зависимостей · Windows, macOS, Linux · MIT

[Read in English](README.md)

> Неофициальный инструмент сообщества для [Claude Code](https://docs.claude.com/en/docs/claude-code),
> ИИ-помощника для программирования от Anthropic. Не связан с Anthropic.

## Зачем это нужно

Claude Code сохраняет каждый разговор у вас на компьютере, в скрытой папке:

```
~/.claude/projects/
├── C--Users-anna-Desktop-shop/        <- чаты, которые шли в C:\Users\anna\Desktop\shop
│   ├── 3f2a…e1.jsonl                  <- один файл = один чат
│   └── memory/                        <- что Claude помнит об этом проекте
└── -home-anna-code-blog/              <- чаты из /home/anna/code/blog
```

Имя папки — это **путь к вашему проекту**. Из-за этого возникают четыре бытовые проблемы:

| Вы… | Что происходит | ClaudeCodeVault |
|---|---|---|
| перенесли или переименовали папку проекта | `claude --resume` на новом месте показывает **пустой список**. Чаты целы, но стали «сиротами» | `move` переносит чаты вместе с папкой |
| хотите бэкап | история — куча непонятных имён папок, плюс форки, которые ссылаются на чужие пути | `backup` с понятными именами |
| сменили компьютер или перешли на рабочий аккаунт | экспортировать проект **вместе** с чатами нечем | `export` / `import` |
| ведёте один чат неделями | каждое сообщение перечитывает всю историю: медленно, дорого, и Claude начинает «забывать» (сжимать контекст) | `init` + привычка `/handoff` |

И ещё одна, о которой мало кто знает: в чатах часто остаются **ключи API и токены**, которые вы
вставили или которые напечатала программа. `scan` найдёт их до того, как вы чем-то поделитесь.

## Установка за 5 минут

### Шаг 1. Проверьте, что установлен Python

Откройте терминал (**Windows:** нажмите `Win`, наберите `PowerShell`, Enter. **macOS:** Терминал.
**Linux:** ваш терминал) и выполните:

```bash
python --version
```

Нужна версия **3.8 или новее**. Если появилась ошибка:

- **Windows:** скачайте Python с [python.org/downloads](https://www.python.org/downloads/).
  На первом экране установщика **поставьте галочку «Add python.exe to PATH»**. Закройте и снова
  откройте PowerShell. (Если `python` открывает Microsoft Store, попробуйте `py --version` и дальше
  пишите `py` вместо `python`.)
- **macOS:** `brew install python` или установщик с python.org; дальше пишите `python3`.
- **Linux:** обычно уже есть как `python3`.

### Шаг 2. Установите ClaudeCodeVault

**Вариант А (рекомендуется): pipx.** Ставит команду `ccvault` в отдельную «песочницу»:

```bash
python -m pip install --user pipx
python -m pipx ensurepath
```

Закройте и снова откройте терминал, затем:

```bash
pipx install git+https://github.com/MyReleases/ClaudeCodeVault
```

**Вариант Б: обычный pip.**

```bash
python -m pip install --user git+https://github.com/MyReleases/ClaudeCodeVault
```

**Вариант В: совсем без установки.** Скачайте файл [`claude_code_vault.py`](claude_code_vault.py)
(кнопка «Download raw file») и запускайте его напрямую: `python claude_code_vault.py status`.
Тогда везде ниже вместо `ccvault` пишите `python claude_code_vault.py`.

### Шаг 3. Проверьте

```bash
ccvault --version
ccvault --help
```

`claude-code-vault` — та же команда, просто длинное имя.

## Первый запуск

**1. Посмотрите, что у вас есть.**

```bash
ccvault status
```

```
PROJECT                          CHATS       SIZE  LAST ACTIVITY
C:\Users\anna\code\shop              4    38.8 MB  2026-10-16 15:41
C:\Users\anna\Desktop\old-blog       3    31.7 MB  2026-10-02 13:53   <- folder missing (orphan)

2 projects, 7 chats, 70.5 MB, 1 orphaned
```

**«Сирота» (orphan)** — чат, папки которого по этому пути больше нет. Обычно её просто перенесли.
Смотрите [Я уже перенёс папку](#я-уже-перенёс-папку-и-чаты-пропали).

**2. Сделайте первый бэкап.** Подойдёт любая папка, лучше та, что синхронизируется с облаком
(OneDrive, Яндекс Диск, Google Drive, iCloud):

```bash
ccvault backup "C:\Users\anna\OneDrive\claude-backup"
```

```
  shop__1a2b3c: 12 new, 0 updated
  old-blog__9f8e7d: 5 new, 0 updated
Backed up 2 projects to C:\Users\anna\OneDrive\claude-backup: 17 new files, 0 updated. Nothing was deleted.
```

Повторяйте когда угодно: копируются только новые и изменённые чаты.

**3. Подготовьте проект к коротким дешёвым чатам** (по желанию, см.
[привычку](#привычка-которая-экономит-больше-всего-токенов)):

```bash
ccvault init "C:\Users\anna\code\shop"
```

## Что делать, если…

### Хочу перенести проект в другую папку

Используйте `ccvault move` **вместо** переноса руками. Сначала посмотрите, что будет:

```bash
ccvault move "C:\Users\anna\Desktop\shop" "D:\code\shop" --dry-run
ccvault move "C:\Users\anna\Desktop\shop" "D:\code\shop"
```

Папка переедет, а чаты скопируются на новое место с исправленными путями. Дальше:

```bash
cd D:\code\shop
claude --resume
```

Старые чаты будут в списке. Перед переносом закройте Claude Code, открытый в этой папке.

### Я уже перенёс папку, и чаты пропали

Они не пропали, а стали «сиротами». Скажите, где папка была и где она сейчас:

```bash
ccvault move "C:\Users\anna\Desktop\shop" "D:\code\shop" --history-only
```

`--history-only` значит «папку не трогай, только перепривяжи чаты».

### Удалил историю (или новый компьютер), но есть бэкап

```bash
ccvault move "C:\старый\путь\shop" "D:\code\shop" --history-only --from-backup "C:\Users\anna\OneDrive\claude-backup"
```

Первый путь — где проект лежал, **когда шли чаты** (его видно в `status` и в `manifest.json`
бэкапа).

### Хочу продолжить на другом компьютере или в рабочем аккаунте

На старом компьютере:

```bash
ccvault export "D:\code\shop" -o shop.zip
```

Если в чатах есть секреты, экспорт остановится и скажет об этом. Добавьте `--redact`, чтобы
замаскировать их в архиве, или `--allow-secrets`, если архив останется только у вас. Тяжёлые
папки, которые собираются заново (`node_modules`, `.venv`, `dist`, `build`…), в архив не попадают;
`.git` попадает (`--no-git`, чтобы убрать).

Перенесите `shop.zip` (флешка, облако), установите там ClaudeCodeVault и выполните:

```bash
ccvault import shop.zip "C:\Users\me\code\shop"
cd C:\Users\me\code\shop
claude --resume
```

Зависимости поставьте как обычно (`npm install`, `pip install -r requirements.txt`…).

### Хочу передать проект коллеге

```bash
ccvault export "D:\code\shop" -o shop-for-max.zip --redact
```

Или только код и заметки HANDOFF, без чатов:

```bash
ccvault export "D:\code\shop" -o shop-code.zip --no-chats
```

### Чат стал длинным и медленным

Напишите в чате `/handoff` (после `ccvault init`), затем откройте **новый** чат и напишите
*«прочитай HANDOFF.md и продолжим»*. Подробнее — в следующем разделе.

### Хочу проверить, не утёк ли ключ

```bash
ccvault scan --all
```

```
C:\Users\anna\code\bot  [a41c09e2]  Telegram bot token x2
Found 2 possible secrets. Anyone you give these chats to can read them.
```

Если нашёлся настоящий ключ, **отзовите его и создайте новый** у сервиса (GitHub, OpenAI,
BotFather…). Удаление чата не отменяет утечку, которая уже случилась.

### Хочу автоматический бэкап

**Windows (Планировщик заданий), каждый день в 21:00:**

```powershell
schtasks /Create /SC DAILY /ST 21:00 /TN "ClaudeCodeVault backup" /TR "ccvault backup C:\Users\anna\OneDrive\claude-backup"
```

**macOS / Linux (cron), каждый день в 21:00:** выполните `crontab -e` и добавьте строку

```
0 21 * * * $HOME/.local/bin/ccvault backup $HOME/claude-backup
```

### Хочу видеть активность по проектам

```bash
ccvault stats --days 7
```

```
Last 7 days
PROJECT                  PROMPTS  CHATS  COMMITS  FILES
D:\code\shop                  23      1       20     58
```

PROMPTS — ваши сообщения, CHATS — чаты с активностью, COMMITS — коммиты git, FILES — изменённые
файлы. `--json` — то же для своих дашбордов.

## Привычка, которая экономит больше всего токенов

Каждое ваше сообщение заставляет Claude перечитать весь разговор. Чат недельной давности — это
мегабайты истории: каждое новое сообщение медленное и дорогое, а потом Claude начинает сжимать
контекст и теряет детали. Помогает привычка из двух файлов:

| Файл | Что в нём | Когда меняется |
|---|---|---|
| `CLAUDE.md` | Что за проект, стек, команды запуска, правила. Claude Code читает его сам в начале каждого чата. **Держите коротким:** он оплачивается в каждом сообщении. | Редко |
| `HANDOFF.md` | Где сейчас работа: цель, что сделано, следующий шаг, решения и почему, известные проблемы. Один экран. | В конце каждого чата |

Порядок работы:

1. **Одна задача — один чат.** Чат «добавить вход», а не чат «проект».
2. Задача сделана или чат разросся — напишите **`/handoff`**. Claude перепишет `HANDOFF.md`.
3. Откройте **новый чат** в той же папке: *«прочитай HANDOFF.md и продолжим»*. Новый чат
   начинает с одного экрана контекста, а не со всей истории.
4. Время от времени — `ccvault backup`, чтобы старые чаты всё равно сохранились.

`ccvault init` создаёт оба файла из шаблонов и команду `/handoff` (`.claude/commands/handoff.md`).
Ваши существующие файлы он не перезаписывает.

## Все команды

Любая команда принимает `--claude-dir ПУТЬ`, если настройки Claude Code лежат не в `~/.claude`
(переменная окружения `CLAUDE_CONFIG_DIR` тоже учитывается).

### `status`
Все проекты с историей: число чатов, размер, последняя активность. Помечает «сирот».
`--json` — вывод для программ.

### `backup ПАПКА`
Копирует всю историю в `ПАПКА/<имя проекта>__<короткий хэш>/…` и пишет `ПАПКА/manifest.json`
(какая папка к какому исходному пути относится). Копируется только новое и изменённое.
Из `ПАПКИ` ничего не удаляется, так что это ещё и архив чатов, которые вы потом удалили.

### `move СТАРЫЙ НОВЫЙ`
Переносит папку проекта и копирует её чаты в папку истории для нового пути, исправляя пути внутри.
Чаты из подпапок проекта тоже переезжают.

| Параметр | Значение |
|---|---|
| `--history-only` | Папка уже на новом месте, только перепривязать чаты |
| `--from-backup ПАПКА` | Взять чаты из бэкапа, а не из `~/.claude` |
| `--dry-run` | Показать, что будет, ничего не меняя |
| `--force` | Перезаписать чаты, которые уже есть на новом месте |

### `export [ПРОЕКТ]`
Один zip: `project/` (ваши файлы), `chats/` (история), `claude-code-vault.json` (откуда это).
По умолчанию — текущая папка, архив кладётся рядом с проектом.

| Параметр | Значение |
|---|---|
| `-o ФАЙЛ` | Куда записать архив |
| `--redact` | Замаскировать всё похожее на секреты в чатах архива |
| `--allow-secrets` | Экспортировать, даже если найдены секреты |
| `--no-chats` | Только код |
| `--no-git` | Без папки `.git` |
| `--exclude ИМЯ` | Не включать ещё одну папку (можно несколько раз) |
| `--include-heavy` | Оставить `node_modules`, `.venv`, `dist`, `build` и т. п. |

### `import ZIP ПАПКА`
Распаковывает экспорт в `ПАПКУ` (пустую или несуществующую) и перепривязывает чаты к ней.
`--force` перезаписывает уже существующие чаты.

### `scan [ПРОЕКТ]`
Ищет в истории ключи и токены Anthropic, OpenAI, GitHub, AWS, Google, Slack, Stripe, Telegram и
приватные ключи. `--all` — все проекты, `-v` — номера строк. Секреты никогда не печатаются
целиком. Код выхода 1, если что-то найдено.

### `stats`
По каждому проекту за последние `--days N` (по умолчанию 7): ваши сообщения, активные чаты,
коммиты git, изменённые файлы. Есть `--json`.

### `init [ПРОЕКТ]`
Создаёт `CLAUDE.md`, `HANDOFF.md` и `.claude/commands/handoff.md`. Существующие файлы сохраняет,
если не указан `--force`.

## Как это устроено

- Claude Code называет папку истории по полному пути проекта, заменяя всё, что не буква и не цифра,
  на `-`: `C:\Users\anna\Desktop\shop` → `C--Users-anna-Desktop-shop`.
- Каждый чат — файл `.jsonl`: одна JSON-запись на строку, в большинстве записей есть поле `cwd` —
  папка, в которой шёл чат.
- Чтобы понять, к какому проекту относится папка истории, ClaudeCodeVault читает эти поля `cwd`
  (поэтому правильно разбирает и форки, которые начинаются с чужого пути).
- `move` и `import` копируют каждый чат в папку для нового пути и меняют в `cwd` старый путь на
  новый. Всё остальное копируется байт в байт, подпапки (`memory/`, результаты инструментов) — как есть.
- Никаких обращений в интернет. Единственная внешняя программа — `git log` для `stats`.

## Безопасность и приватность

- **Ничего не удаляется.** `move` оставляет старую историю на месте (в `status` она станет
  «сиротой»; удалите её сами, когда убедитесь, что всё в порядке). `backup` только добавляет.
- `move` не перезаписывает существующую папку, а существующие чаты — только с `--force`.
- `import` проверяет все пути внутри архива **до** записи первого файла.
- `scan` и `export` показывают только замаскированное начало секрета.
- **Ваши чаты — личные данные.** В них ваш код, содержимое файлов, которые читал Claude, вывод
  команд и всё, что вы вставляли. Относитесь к экспорту как к копии папки проекта.

## Ограничения

- **Боковая панель приложения Claude.** Приложение хранит свой список сессий. После `move`
  продолжайте в терминале (`claude --resume`) или начните новый чат в новой папке; старые пункты
  в боковой панели могут ссылаться на прежний путь.
- **Очень длинные пути** (больше ~200 символов): новые версии Claude Code могут сокращать имя
  папки истории, и перенесённый чат может не появиться в `--resume`. Поиск истории при этом
  работает. Если столкнётесь — откройте issue.
- **Точки отката файлов.** Пути в снимках файлов не переписываются, поэтому `/rewind` правок,
  сделанных *до* переноса, может не найти файлы.
- Только Claude Code (агент в терминале, IDE и приложении). Чаты на claude.ai хранятся у Anthropic,
  а не на вашем компьютере; их можно выгрузить в claude.ai: Настройки → Конфиденциальность →
  Экспорт данных.
- Сделано под формат чатов Claude Code 2.1.x.

## Вопросы и ответы

**Отправляет ли он мои чаты куда-то?** Нет. Работает только с файлами на вашем компьютере, в
интернет не ходит.

**Не сломает ли он Claude Code?** Существующие файлы истории он не меняет. Он только добавляет
копии (с исправленными путями) и новые файлы.

**Можно запускать `backup` в одну и ту же папку каждый день?** Да, так и задумано: копируется
только изменённое.

**Можно отменить `move`?** Да: `ccvault move НОВЫЙ СТАРЫЙ` вернёт папку, а исходная история и так
не удалялась.

**Работает с другими ИИ-помощниками?** Пока нет, только с форматом Claude Code.

## Удаление

```bash
pipx uninstall claude-code-vault        # или: python -m pip uninstall claude-code-vault
```

Ваши бэкапы и архивы остаются там, куда вы их положили.

## Участие

Issues и pull requests приветствуются, особенно отчёты с macOS/Linux и с очень большой историей.
Тесты:

```bash
python -m unittest discover -s tests -v
```
